Step 3

Dispatch Leads

Send from verified keep rows by default. The queue uses Email + FirstName only, so the email still says Hi {FirstName},. Cleaned mode stays available, and all senders must be stopped first. Dispatch is the fast queue-safety/write stage.
Dispatch Source Verified mode reads _important/leads_verified.csv. Cleaned mode keeps the legacy _important/leads.csv path.
Dispatch Rule Astra + one SendGrid shard per lead If Astra has not sent or queued the lead, it goes to recipients_private_jc.csv. If SendGrid has not sent or queued it, it goes to exactly one SendGrid shard.
Dispatch is idle. Check the master file first, then dispatch while all senders are stopped.
